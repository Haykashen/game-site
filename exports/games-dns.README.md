# Объединённый каталог DNS и Showgames: PlayStation, Xbox и Nintendo

Файл: `games-dns.json` (UTF-8). Структура: `games[] → platforms[] → editions[] → images[]`.

Проверено по исходному HTML:

- 1 738 уникальных `data-product`: 1 192 PlayStation, 522 Xbox и 24 Nintendo — все сохранены.
- Дополнительно 2 533 уникальных товара Showgames, 2 536 записей платформ/изданий.
- Всего 2 211 групп игр; 3 083 группы платформ; 3 803 логических издания.
- Исходных записей «товар + платформа» — 4 448; повторения сведены в `products[]` внутри издания.
- Аудит: 613 групп совпавших изданий. Отчёт — `games-dns-duplicates.json`.
- Товар с несколькими платформами присутствует под каждой с одним исходным ID.
- Изображения есть у всех товаров: DNS — из `<picture>`, Showgames — строго из `img.pic-1`.
- Даты выпуска указаны для 1 621 товара; отсутствующие или явно ошибочные даты — `null`.
- Xbox-выгрузка отдельно сохранена в `games-dns-xbox.json`: 401 группа игр,
  522 товара, 692 записи платформ/изданий. Среди товаров 81 цифровой и 14 дополнений.
- Nintendo-выгрузка отдельно — `games-dns-nintendo.json`: 24 товара. У 7 товаров
  Switch уточнён до Switch 2 по официальным страницам; ссылки — в `platformAnnotation`.
- Метаданные шести исходных HTML и SHA-256 — в `source.files`.

## Обложки Showgames

`showgames-ps3.json`, `showgames-ps4.json`, `showgames-ps5.json` сохраняют разбор
новых HTML отдельно. Платформа берётся из имени файла. Из 2 543 карточек исключены
7 позиций (валюта, зарядная станция, комплекты без игры); три товара встречаются
на разных платформах. Сохраняются title, URL товара, исходный артикул, надпись цены,
язык, явно указанный регион и дополнительные пометки. Цены не создают объявления.

ID Showgames имеют пространство имён `showgames-<артикул>`, а ID издания в БД —
`showgames-<артикул>-ps3|ps4|ps5`. Поля DNS у них не заполняются. Прежние ID сохранены.
Обложки Showgames стоят первыми в `images[]` логического издания, ссылки DNS — следом.
Карточки и галерея автоматически пробуют следующий URL при ошибке загрузки.

`catalogueIdentity` — связь с единственным совместимым изданием DNS. Например,
«русская версия» совместима с уже известным русско-английским изданием, но не
доказывает наличие других языков: исходный `interfaceLanguages` товара сохранён.
Явно несовместимые регионы/языки и неоднозначные совпадения не объединяются.
Проверенные соответствия названий — `showgames-matches.json`; нечёткий поиск не используется.

Повторное извлечение: `node scripts/extract-showgames-catalog.cjs INPUT.html OUTPUT.json`.
Объединение: `node scripts/merge-showgames-catalog.cjs exports/games-dns.json OUTPUT.json exports/showgames-ps3.json exports/showgames-ps4.json exports/showgames-ps5.json`.

## Поля и идентификаторы

В `schemaVersion: 2` издание — одна логическая карточка. При нескольких товарах
внутри есть `products[]` с полными исходными записями и `productIds[]`.
У DNS `id` каждого товара строго равен `data-product`, `code` — `data-code`;
у общей карточки `id` — ID выбранного товара группы.
У общей игры `id` равен `data-product` первого встретившегося товара группы,
а `productIds` перечисляет все её товарные ID. Это идентификатор группы данной
выгрузки, а не ID игры в production-каталоге DiscVault.

`sourceTitle` сохраняет полное значение атрибута `title` ссылки названия товара
с декодированными HTML-сущностями и нормализованными пробелами. Названия игры
и издания выделены из него. `sourceGameTitles` содержит варианты исходного
названия, вошедшие в группу.

Дополнительно: URL товара, дата его выпуска, возрастное ограничение, жанры,
языки интерфейса/субтитров и озвучки, цена в рублях, рейтинг, число отзывов
и вопросов, показатель надёжности, статус наличия и исходные характеристики.
Это данные сохранённого HTML, их актуальность отдельно не проверялась.

У товаров DNS `images` содержит все реальные URL из `src`, `data-src`, `srcset`, `data-srcset`
внутри `<picture>`. `image` — первый URL после сортировки по размеру thumbnail;
`imageVariants` сохраняет размеры из URL, формат, media и источники атрибутов.
Разные разрешения одного изображения оставлены. `advertisedImageCount` —
заявленное в HTML количество изображений: сама галерея могла сохраниться не
полностью, отсутствующие ссылки не достраиваются. Изображения не скачивались.

## Группировка

Учитываются регистр, пунктуация, апострофы, диакритика и небольшой явный словарь
локализованных названий. Названия изданий, например Complete, Deluxe, GOTY,
Director's Cut и PlayStation Hits, выделяются отдельно. Разные товарные ID
не схлопываются, даже если название издания совпадает: могут отличаться языки,
дата или комплект поставки. Неуказанное издание обозначено «Не указано».

Xbox ONE приведён к Xbox One; поддерживаются Xbox 360, Xbox One, Xbox Series S,
Xbox Series X, включая старые записи `Xbox One/Series X` и `Xbox One\\Series X`.
Русские названия известных игр сопоставлены с английскими явным словарём.
Цифровые товары сохраняют `editionType`, дополнения — `contentType: addon`
и название «Дополнение: ...» внутри базовой игры. Исходные тексты не удаляются.

Siege X сопоставлен с Rainbow Six Siege по
[официальному описанию Ubisoft](https://toronto.ubisoft.com/ubisoft-toronto-enters-the-operation-on-rainbow-six-siege-x/),
Gone Fission — с Fallout 76 по
[примечаниям Bethesda](https://fallout.bethesda.net/en-US/news/fallout-76-gone-fission-release-notes).
Эти уточнения отмечены в `groupingAnnotation`. У Xbox FC 27 дата 25.09.2006
сохранена в `releaseDateText`; `releaseDate: null` и `dataQualityNotes`
помечают её как требующую проверки.

Ремейки, ремастеры и сборники с отдельными названиями сохранены отдельно от
оригиналов. Resident Evil 4 Gold Edition отнесено к ремейку по
[официальному сообщению Capcom](https://www.capcom.co.jp/ir/english/news/pdf/e240313.pdf);
это уточнение явно отмечено в `groupingAnnotation`. Дата товара из DNS не исправлялась.
Группировка основана на названиях; это подготовленная выгрузка, не сопоставление
с внутренними ID базы DiscVault. При импорте сохраняются существующие ID игры
и издания; повторный запуск не создаёт новые записи.

## Повторная выгрузка

```powershell
npm install --prefix .deploy/tools --no-save --package-lock=false cheerio
node scripts/extract-dns-catalog.cjs "C:/Users/Hayka/Downloads/game-dns-Nintendo.html" exports/games-dns-nintendo.json
node scripts/merge-dns-catalog.cjs exports/games-dns.json exports/games-dns-nintendo.json exports/games-dns.json
node --test scripts/extract-dns-catalog.test.cjs
```

Объединение сохраняет существующие группы и товарные записи, добавляя платформы
и товары. Конфликт назначения одного ID разным играм останавливает обработку.

Повторы группируются по игре, платформе, названию издания, региону, языкам
интерфейса и носителю. Различия озвучки, артикулов, дат и изображений сохраняются
в вариантах поставки. Данные не удаляются: в БД варианты указывают на основное
издание через `canonical_id`. Копии и объявления ссылаются на основную карточку,
старые ID разрешаются в неё. На сайте можно раскрыть «Варианты поставки».

В JSON записаны SHA-256 исходников, время извлечения, статистика и правила полей.
Проверены все товарные ID, соответствие `sourceTitle` атрибутам HTML и точное
совпадение множества ссылок из `<picture>` для каждого товара. Шесть тестов
покрывают группировку, HTML-сущности, картинки, несколько платформ, старый формат
названий, разделение оригинала и ремейка и извлечение характеристик.
