Nintendo-пакет: 24 товара, 18 новых игр, 6 совпадений с текущим каталогом.
Включены Nintendo Switch и Nintendo Switch 2 с проверенными уточнениями платформ.
План после загрузки: 928 игр, 1 917 исходных строк изданий, из которых 25
сохранены как варианты поставки; публичных логических изданий — 1 892.

Миграция `20261026000400_edition_variants` добавляет nullable `canonical_id`.
Импортёр в одной транзакции добавляет новые записи и объединяет 24 группы
совпавших изданий. Дубликаты не удаляются: сохраняются все исходные поля, SKU,
артикулы и изображения. Копии и объявления перенаправляются на основное издание.
Старые API/URL ID продолжают разрешаться в основное издание; каталог отдаёт
варианты во вложенном `variants[]`, а фронтенд показывает одну карточку.

Сравниваются игра, платформа, название, регион, языки интерфейса и носитель.
Разная озвучка сохраняется во вложенных вариантах поставки. Разные платформы,
регионы, носители и интерфейсные языки автоматически не объединяются.
Повторный импорт после объединения не восстанавливает лишние карточки.

Резервная копия и отчёты:
`/opt/game-site/.deploy/catalog-imports/dns-nintendo-001/`.

Источник: `exports/games-dns.json`. Импортёр: `scripts/import-dns-catalog.cjs`,
чистое планирование: `scripts/lib/dns-catalog.cjs`.

Импорт отдельно от демонстрационного seed. Он не запускается автоматически
при сборке, старте API или развёртывании. Рабочая директория CLI — `/app/server`;
должны быть доступны актуальные Prisma Client и DATABASE_URL.

1. Создать резервную копию PostgreSQL и проверить её через `pg_restore --list`.
2. Применить миграцию `20261026000300_unique_game_titles` через Prisma.
3. Запустить CLI с JSON без флагов: это предварительный план, без записи.
4. Проверить сопоставление существующих игр, количество создаваемых записей
   и сохранить `hash` из плана.
5. Запустить с `--apply --expect=HASH`. Если каталог изменился и план расходится,
   запись не выполняется. Применение — одна транзакция с блокировкой таблиц игр
   и изданий. Повторный запуск не создаёт дубликатов.

Исходные игры сопоставляются с существующими по нормализованному названию,
включая явные соответствия God of War (2018), Spider-Man (2018), RE2 (2019),
RE4 (2023). Существующие ID, названия, годы, разработчики, издатели и описания
сохраняются. Обложка игры заполняется только при пустом значении.

Для новых игр известны название и жанры. Неизвестный год первого выпуска —
`null`, прочие отсутствующие факты — пустые строки. Даты товаров записываются
в `Edition.releaseDate`, без подмены года первого выпуска игры.

Издания сопоставляются по `dnsProductId` и платформе; их существующие ID
сохраняются. Новые издания получают `id=data-product`; у четырёх товаров,
предназначенных сразу для PS4/PS5, используются два ID с суффиксами `-ps4`,
`-ps5`, а `dnsProductId` в обоих случаях остаётся исходным UUID.
Для Xbox также используются суффиксы `-xbox-one`, `-xbox-series-s`,
`-xbox-series-x` у многоплатформенных товаров. Существующие ID не меняются.
Язык — язык интерфейса/субтитров. Явные цифровые издания получают носитель
«Цифровое издание»; дополнения подписаны «Дополнение: ...» и в описании.
Регион, неизвестный носитель и состав комплекта не
выдумываются. Цены DNS и его рейтинги не превращаются в пользовательские
объявления и оценки DiscVault.

`coverImages` содержит прямые HTTPS-ссылки DNS. Размерные варианты одной
картинки схлопываются до лучшего доступного разрешения; разные изображения
сохраняются. Пользовательские изображения, не относящиеся к DNS, не заменяются.
Файлы не скачиваются и не копируются в uploads. В карточке выбор издания
меняет весь набор изображений; если изображений несколько, доступны стрелки.
Для внешних изображений используется `referrerPolicy=no-referrer`; ошибка
загрузки отображается без подстановки обложки другого издания.

Уникальность названий защищена в PostgreSQL: точный UNIQUE и дополнительный
индекс без учёта регистра и повторяющихся/краевых пробелов. Если в базе уже
есть конфликтующие названия, миграция завершается ошибкой, сохраняя записи.

Резервная копия, исходный пакет и отчёты на VPS:
`/opt/game-site/.deploy/catalog-imports/dns-001/`.
