# Наполнение каталога

`games-batch-001.json` — первые 20 новых игр, добавленные в production 26.10.2026.
После импорта: 23 игры. Существующие 3 записи сохранены без изменений.
В каждой записи указаны официальные источники; описания составлены для каталога.
Издатель относится к международному консольному выпуску; год — к первому выпуску
указанной игры, а не её последующему порту или переизданию. Ремейки RE2 и RE4
явно различаются по году. `coverImage` пустой. Издания заполняются отдельно.

## Повторное использование

Импортёр `scripts/import-catalog-games.cjs` запускается из рабочей директории
API `/app/server`, где доступны Prisma Client и `DATABASE_URL`.

1. Создать и проверить резервную копию PostgreSQL (`pg_dump -Fc`, `pg_restore --list`).
2. Передать JSON и импортёр в контейнер API.
3. Проверить план без записи:

   ```sh
   node /tmp/import-catalog-games.cjs /tmp/games-batch-001.json
   ```

4. Применить проверенный пакет:

   ```sh
   node /tmp/import-catalog-games.cjs /tmp/games-batch-001.json --apply
   ```

Импорт выполняет только INSERT в `games`, пропуская совпадения по ID или
нормализованному названию. В одной транзакции проверяются неизменность всех
существовавших игр и количество пользователей, изданий, экземпляров, объявлений,
ставок, сделок и оценок. При нарушении проверок транзакция откатывается.
Повторная предварительная проверка после production-импорта: `planned: []`.

Импорт не запускается автоматически при сборке, развёртывании или старте API.
Общий демонстрационный `db:seed` для наполнения production не используется.
Резервная копия и отчёты первого импорта находятся на VPS:
`/opt/game-site/.deploy/catalog-imports/games-001/`.
