# RetroKeep

Каталог коллекционных изданий видеоигр: каталог, карточки игр, аналитика цен,
лоты продаж и покупок, личная коллекция. Проект — React-переписывание
однофайлового прототипа `retrokeep_stage2.html` с сохранением визуального языка
и сборкой в **один HTML-файл**. Сейчас добавлены каркас сайта (сайдбар,
верхняя панель, мобильная навигация, hash-роуты) и переработанная панель
каталога: поиск, кастомные фильтры, чипы и URL-состояние.

## Стек

- React 19.3 + TypeScript 7.0 (строгий режим, без `any`)
- Vite 8 + `vite-plugin-singlefile`
- `react-router-dom` 7 — `HashRouter`, чтобы собранный файл работал с `file://`
- `lucide-react` вместо CDN-скрипта Lucide
- Стартовые данные — JSON в `src/data`; коллекция и новые лоты — `localStorage`,
  ключи совместимы со старой версией

## Команды

```bash
npm install       # зависимости
npm run dev       # dev-сервер
npm run typecheck # проверка типов
npm run build     # typecheck + сборка в dist/index.html и retrokeep_stage3.html
npm run preview   # предпросмотр production-сборки
```

Готовый файл: **`dist/index.html`**. `postbuild` дополнительно кладёт копию в
`retrokeep_stage3.html` в корне для удобства. Оба файла генерируются сборкой и
не коммитятся — они перечислены в `.gitignore`. CSS и JS встроены внутрь, файл
открывается напрямую с диска. Единственный внешний ресурс — Google Fonts
(как и в исходной версии).

## Разделы и маршруты

| Маршрут       | Раздел                                              |
| ------------- | --------------------------------------------------- |
| `#/games`     | Каталог с фильтрами и карточкой игры (drawer)        |
| `#/auctions`  | Аукционы — заглушка с будущими фильтрами            |
| `#/listings`  | Объявления: продажа, покупка, обмен                 |
| `#/collection`| Коллекция + место под достижения                    |
| `#/stats`     | Статистика — заглушка под диаграммы                 |
| `#/account`   | Аккаунт: профиль, доставка, рейтинг                 |
| `#/settings`  | Настройки: рабочая тема, язык, валюта               |
| `#/`          | Редирект на `#/games`                               |

## Навигация

- **≥1280 px** — сайдбар 264 px с группами «Маркет» и «Моя полка», аккаунт-блок
  внизу. «Аккаунт» открывается из блока, «Настройки» — шестерёнкой в нём.
- **1024–1279 px** — сайдбар сжимается до рейла 78 px с иконками и подсказками.
- **<1024 px** — сайдбар скрыт, работает нижний таб-бар. Пятый пункт «Ещё»
  открывает bottom-sheet со статистикой, аккаунтом и настройками.
- Верхняя панель: заметный заголовок раздела, язык, тема и аватар. Поиск из
  верхней панели убран — он живёт в панели каталога.
- Каталог показывает все игры; «Моя коллекция» — отдельный раздел. Вкладки
  «Каталог / Моя Коллекция» и крупный hero-заголовок удалены.
- Панель фильтров: поиск с очисткой, счётчик результатов, кастомные выпадающие
  списки с группами платформ и галочкой выбора, активные чипы и сброс всех
  фильтров. Состояние хранится в URL: `q`, `platform`, `lang`, `year`.

## Совместимость со старой версией

- `src/styles.css` — исходный блок `<style>` из `retrokeep_stage2.html` с
  правками иконок (`i` → `svg`), стилями shell и переработанной панелью
  каталога. Стили карточек и модалки сохранены.
- Стартовые игры, лоты и справочники вынесены в JSON-файлы `src/data`. Они
  импортируются при сборке и встраиваются в single-file HTML, поэтому `file://`
  продолжает работать без запросов к серверу.
- Сохранены ключи `retrokeep_games`, `retrokeep_owned`, `theme` и структура
  данных. Лоты, сохранённые старой версией без `id`, получают его при загрузке.
- Поведение каталога проверено автоматически в браузере: поиск, кастомные
  фильтры, чипы, сброс, URL, клавиатура, коллекция, добавление лота,
  перезагрузка, тема, закрытие по Escape/фону.
- Геометрия каталога сверена на 1440 и 390 px в тёмной и светлой темах.
  Каркас дополнительно проверен на 1440, 1024 и 390 px.

## Осознанные улучшения

- JSX вместо `innerHTML` — пользовательские строки больше не могут внедрить HTML.
- Безопасный парсинг `localStorage`: битые данные не ломают приложение.
- JSON-данные проходят через те же проверки, что и `localStorage`; обязательные
  поля проверяются типами при сборке, а лоты связываются с играми по `gameId`.
- Цвета платформ хранятся в `platforms.json`, а не в CSS, поэтому новый бейдж
  не требует правок стилей.
- Строгая типизация, дискриминированный union для типов лотов, чистые функции
  фильтрации и аналитики.
- `React.memo` для карточек, мемоизация фильтрации и аналитики.
- Доступность: `role`/`aria`, открытие карточки с клавиатуры, фокус-трап в
  модалке, возврат фокуса, `aria-modal`, подписи у полей, `aria-current` у
  навигации, закрытие sheet по Escape.
- Тема применяется до первой отрисовки (без вспышки), цена валидируется (> 0),
  фильтр «После 2010» больше не зависит от захардкоженного 2026 года.
- Форматирование цен зафиксировано на `ru-RU` (детерминированный вид).
- Контексты темы и коллекции убрали дублирование состояния между страницами.
- Все фильтры каталога хранятся в URL и переживают перезагрузку; ссылкой можно
  поделиться. Ввод в поиск использует `replace`, чтобы не засорять историю.
- Кастомный `FilterDropdown` — ARIA-listbox с группами, галочкой, клавиатурой
  (Arrow/Home/End, Enter, Escape), закрытием по клику вне и возвратом фокуса.
- Заголовок документа и верхней панели обновляются при смене раздела.

## Иконки

В старой версии Lucide заменял `<i data-lucide>` на `<svg>`, из-за чего часть
CSS-правил с селекторами `i` не срабатывала. В React-версии селекторы обновлены
на `svg`:

- переключатель темы показывает солнце в светлой теме и луну в тёмной;
- иконка поиска находится внутри поля ввода, а не в потоке над ним;
- иконка диска на обложке — 44 px (34 px на мобильных).
