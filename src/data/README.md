# Данные каталога

Исходные данные лежат в JSON-файлах. Они импортируются на этапе сборки и
попадают внутрь single-file бандла: приложение не делает `fetch`, поэтому
собранный `index.html` по-прежнему работает через `file://`.

Пользовательские изменения — коллекция и лоты маркета — хранятся отдельно
в `localStorage` и не перезаписывают эти файлы.

## Файлы

| Файл            | Что содержит                                              |
| --------------- | --------------------------------------------------------- |
| `platforms.json`| платформы, их группы и цвета бейджей                       |
| `filters.json`  | языки, регионы, издания, комплектность, диапазоны годов    |
| `games.json`    | игры без лотов                                             |
| `lots.json`     | лоты с привязкой к игре через `gameId`                     |
| `market.json`   | демо-объявления и аукционы для разделов маркета            |
| `index.ts`      | типизированная загрузка, группировка и сборка `Game[]`     |

## Форматы

### `platforms.json`

```json
{
  "name": "PS5",
  "group": "PlayStation",
  "color": "#2563eb",
  "textColor": "#ffffff"
}
```

`color` и `textColor` подставляются в бейдж платформы на карточке и в модалке.
Группы в фильтре строятся по полю `group` в порядке массива.

### `filters.json`

Справочники для фильтров и карточки: `languages`, `regions`, `editions`,
`completeness`, а также `yearRanges`.

`yearRanges[].max: null` означает открытый верхний диапазон («После 2010»).
При загрузке он превращается в `Number.POSITIVE_INFINITY`.

Значения `region`, `edition` и `completeness` в `games.json` должны быть в
этих списках — иначе загрузчик бросит ошибку с подсказкой.

### `games.json`

Поля игры: `id`, `title`, `platform`, `publisher`, `developer`, `series`,
`year`, `lang`, `region`, `edition`, `completeness`, `media`, `description`.
Лоты сюда не кладутся.

`platform`, `lang`, `region`, `edition` и `completeness` проверяются по
справочникам `platforms.json` и `filters.json`. `developer`, `series` и
`media` — свободный текст.

### `lots.json`

Поля лота: `gameId`, `id`, `type` (`sale` или `purchase`), `title`,
`condition`, `user`, `price`.

### `market.json`

Демо-записи для разделов «Аукционы» и «Объявления». Поля: `id`, `kind`
(`listing` или `auction`), `gameId`, `title`, `edition`, `region`, `condition`,
`price`, `seller`, `description`, `photos`, `deliveryServices`,
`internationalShipping`, `packagingPrice`, `shipsFrom`, `bids`, `bidStep`,
`startsAt`, `endsAt`, `createdAt`.

- `gameId` должен существовать в `games.json`.
- `edition` и `region` — издание и регион конкретного экземпляра. Значения
  должны быть из `filters.json`; форма подставляет их из выбранной игры, но
  автор может выбрать другой вариант.
- `seller` — автор лота. В форме поле не показывается: для локальных записей
  туда автоматически попадает текущий пользователь («Вы»).
- У объявления `bids: 0`, `bidStep: null`, `startsAt: null` и `endsAt: null`.
- У аукциона `bids` — неотрицательное число ставок, `bidStep` — положительный
  целый шаг цены в рублях, `startsAt` и `endsAt` — ISO-дата и время открытия и
  закрытия. Дата закрытия должна быть позже даты открытия.
- `createdAt` — ISO-дата публикации.
- `photos` — массив до шести изображений в виде `data:image/...` URL. У демо-
  записей он обычно пустой. Пользовательские фото сжимаются в браузере и
  попадают в тот же массив при сохранении лота.
- `deliveryServices` — непустой массив без повторов из `russian-post`, `cdek`,
  `yandex`, `other`. В интерфейсе они подписаны как «Почта России», «СДЭК»,
  «Яндекс Доставка» и «Другое».
- `internationalShipping` — `true` или `false`: готов ли автор отправлять в
  другие страны.
- `packagingPrice` — неотрицательное целое число рублей. `0` значит
  «Бесплатно»; в пользовательских записях `null` означает «Не указана».
- `shipsFrom` — город или регион отправки, непустая строка до 80 символов.
- Пользовательские записи добавляются в `localStorage` (`retrokeep_market`) и
  показываются вместе с демо-записями; этот файл они не меняют.

### Фотографии

Форма размещения принимает изображения до 10 МБ, уменьшает длинную сторону до
1200 px и перекодирует в JPEG. В галерее показываются до шести фото на лот.
Старые записи без поля `photos` читаются как лоты без фотографий.

## Как добавить игру

1. Добавьте объект в `games.json`.
2. Добавьте её лоты в `lots.json` с тем же `gameId`.
3. Если используется новая платформа, добавьте её в `platforms.json`.
4. Если появился новый регион, издание или комплектность — добавьте значение в
   `filters.json`.
5. Запустите `npm run typecheck` — загрузчик проверит обязательные поля.
