# Чаты — локальная версия для согласования

Публиковать после утверждения пользователем страницы чатов и карточки объявления.
Не отправлять текущие изменения в main до утверждения: push запускает Actions.

Реализованы диалоги по объявлению и личные диалоги из профиля, история с загрузкой
предыдущих сообщений, поиск по чатам, непрочитанные, отметка прочтения, черновики
при переключении диалогов, повторная отправка с тем же clientId. Обновление списка
и открытого диалога — каждые 4 секунды. Вложения и групповые чаты не включены.

API `/api/v1/chats` требует сессию. Создание принимает ровно одно поле: entryId или
userId. История, отправка и отметка прочтения проверяют членство. Новый разговор
невозможен с собой или неактивным пользователем; скрытые объявления недоступны.
Отправка ограничена 30 сообщениями в минуту и 4000 символами. Все тексты выводятся
как текст React. Повторный запрос сообщения определяется по authorId/clientId.

Миграция `20261031000100_chats` создаёт только chats/chat_members/chat_messages;
существующие таблицы и данные не удаляются. Chat.title хранит контекст объявления
на момент начала диалога. Подтверждённую публикацию сопровождать обычным backup
PostgreSQL и ручным разрешением новой миграции в Actions.

Локальная проверка использует отдельный `prisma dev --name discvault-chats`.
Адрес runtime при подготовке: localhost:51218. Для него DATABASE_URL дополняется
`connection_limit=1&pgbouncer=true`, чтобы не конфликтовали prepared statements.
Никогда не заменять его адресом production при запуске тестовых сценариев.

`scripts/chats.database.test.ts` выполняется только при CI=true и базе discvault_ci
или при CHATS_LOCAL_TESTS=true и localhost:51218. Проверяет гостя, постороннего,
контакт автора, одновременное открытие одного диалога, повтор отправки, пустой текст,
непрочитанные, чтение, историю 60 сообщений, симметричный личный диалог и блокировку.
CHATS_KEEP_PREVIEW=true оставляет локальные тестовые данные для просмотра;
по умолчанию тест удаляет только созданные им записи по UUID.
