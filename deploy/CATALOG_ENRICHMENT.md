# Автоматическое дополнение каталога

Утилита работает без Gemini и без платных API. Источник — открытые структурированные данные Wikidata. Сбор выполняется пакетными SPARQL-запросами; запросы последовательные, с паузами и повторением временных ошибок.

1. Вход: exports/research-2026-10-30/games-to-complete.json (публичная выгрузка неполных игр).
2. Сбор: node scripts/research-game-metadata.cjs
3. Подготовка импорта: node scripts/prepare-game-enrichment.cjs
4. Проверка синтаксиса: bash -n deploy/enrich-game-metadata.sh
5. Сохранить сгенерированный deploy/enrich-game-metadata.sh в репозитории. Запустить workflow enrich-game-metadata.yml вручную.

## Что заполняется

Только пустые year, developer, publisher, description; жанры связываются со справочником только у игр без жанров. Action RPG разбивается на Action и RPG. Название, ID, издания, регионы, обложки и существующие непустые данные не изменяются.

Описание — краткая справочная сводка подтверждённых данных, а не пересказ сюжета. Издателей и разработчиков может быть несколько: исходные сведения относятся к игре в целом, включая выпуски для разных платформ. Названия компаний взяты из Wikidata на английском или универсальном языке mul.

## Проверки соответствия

- Точное название или точный псевдоним на английском/универсальном языке.
- Совпадение должно относиться к видеоигре/сборнику/переизданию, а не серии, саундтреку или настольной игре.
- При нескольких сущностях с одинаковым названием запись пропускается.
- Будущие даты не подставляются как уже состоявшийся выпуск.
- Даты и свойства могут быть неполными или ошибочными в самом Wikidata: автоматическая проверка соответствия не является независимым фактчекингом. Источники сохраняются для последующей проверки.

## Безопасность импорта

В подготовленном манифесте указаны ID, неизменяемое название, разрешённые поля и URL сущности-источника. Перед изменениями workflow сохраняет JSON затрагиваемых записей и источников в .deploy/backups. Импорт заново проверяет название и пустоту каждого поля, выполняет транзакции партиями по 25 записей с Serializable. Изменения, внесённые пользователями после выгрузки, не затираются. Повторный запуск пропускает уже заполненное.

Основные результаты:
- wikidata-research.json — полный журнал: найденные, неоднозначные, ненайденные и ошибки;
- verified-updates.json — подготовленные дополнения со ссылками;
- enrich-game-metadata.sh — исполняемый манифест для рабочей базы (ключи API и учётные данные в нём отсутствуют).

Утилита сохраняет промежуточный результат после каждой партии и продолжает с контрольной точки. Повторный запуск повторяет только ошибки; для полного повторного исследования следует сохранить старый отчёт отдельно и убрать wikidata-research.json.
