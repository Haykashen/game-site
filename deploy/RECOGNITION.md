# Распознавание игр по фотографии

В форме нового объявления или аукциона доступен блок «Заполнить по фотографии».
Поддерживаются файл JPEG/PNG/WebP до 5 МБ, прямой HTTPS URL без перенаправлений
или первое фото объявления. Отправка изображения в Gemini происходит только
по кнопке «Распознать игру». Распознанные значения применяются после подтверждения.

## Подключение

В серверном окружении (server/.env локально, .env установки на VPS):

GEMINI_API_KEY=<ключ Google AI Studio>
GEMINI_MODEL=gemini-3.5-flash-lite

Ключ не передавать в браузер, чат или git. Модель можно заменить переменной.
После изменения переменных окружения нужно пересоздать контейнер api.
Применить Prisma migration 20261029000000_recognition_review перед запуском нового API.
Без ключа возвращается понятная ошибка; ручное заполнение продолжает работать.
Бесплатность и квоты зависят от выбранной модели и аккаунта поставщика.

## Поведение

- Игра и издание ищутся в каталоге, платформа сопоставляется со справочником.
- При неоднозначности пользователь выбирает конкретную запись.
- Новые записи создаются только по подписанному результату анализа, после
  подтверждения, с recognitionPending=true. Этот столбец доступен в разделе
  администратора «Данные» для фильтрации и снятия пометки после проверки.
- Неопределённые издатель, дата, язык и регион не выдумываются.
- Подтверждение действует 10 минут, привязано к пользователю и сбрасывается
  после перезапуска API. На текущем одноэкземплярном API это намеренно;
  для нескольких реплик нужен общий серверный секрет либо хранилище результатов.
- Новая игра и издание создаются атомарно под advisory lock по названию.
- Для неизвестных записей изображение сохраняется существующим механизмом
  uploads/S3; внешние ссылки остаются ссылками. Загрузка до подтверждения может
  оставлять неиспользованные файлы; автоматическое удаление здесь не включено.
- URL скачивается сервером с проверкой публичного IPv4 и фиксацией адреса DNS,
  без редиректов, с лимитом размера и времени. IPv6-only URL пока не поддерживаются.
- Состояние диска, стоимость и доставка не заполняются моделью.

npm run typecheck:server
npm run build:all
node --import tsx --test scripts/recognition.test.ts scripts/admin-data.test.ts

Тесты Gemini используют имитацию ответов, реальный запрос требует API-ключа.
